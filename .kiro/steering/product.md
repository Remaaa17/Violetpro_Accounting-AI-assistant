# Product Overview

## What It Is
An AI-powered accounting assistant that helps users analyze financial transactions using natural language queries. The system displays a dashboard with financial metrics and provides an interactive AI chatbot powered by Google Gemini.

## Core Features
- **Interactive Dashboard**: Real-time financial metrics (income, expenses, balance, transaction count)
- **AI Assistant**: Natural language queries about financial data using Google Gemini API
- **Transaction Management**: View and analyze journal entries from accounting data
- **Data Visualization**: Charts and graphs via Recharts library
- **Responsive UI**: Works across desktop and mobile devices

## Key Use Cases
Users can ask questions like:
- "What are my total expenses?"
- "Which category has the highest expenses?"
- "What is my current balance?"
- "Show me expenses for rent"

## Target Users
Accounting professionals, small business owners, and finance teams who need quick insights from their financial data.

## Data Model
The system works with **journal entries** (transactions) that follow double-entry bookkeeping:
- Each transaction has: entry_id, date, transaction_type, account_debited, account_credited, amount, narration
- Income sources: Sales Revenue, Interest Income
- Expense categories: Rent Expense, Salaries Expense, Depreciation Expense
